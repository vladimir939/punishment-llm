# Survey instrument

The two counterbalanced forms were generated by `build_forms.gs`, which is the
authoritative record of their content: running it reproduces both versions
exactly, including item order and the attention check.

The live form links are not published here. A published editing link would let
anyone alter the instrument or read the raw responses, which still carry
submission timestamps. Exported responses are converted by `import_forms.py`
into `data/humans.csv`, which holds only a sequential respondent id.
